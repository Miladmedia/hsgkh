# هیئت شهدای گمنام خلیل شهر | Android

پروژهٔ تک‌ماژولی Kotlin/Jetpack Compose با رابط فارسی RTL، ظاهر تیره و کارت‌های نیمه‌شفاف (glassmorphism)، فیلتر هشتگ، تازه‌سازی دستی، کش محلی و بررسی پس‌زمینه است. پروژه پست نمونه/جعلی ندارد؛ اگر منبع عمومی دادهٔ قابل‌استخراج ندهد، صفحهٔ خالی با توضیح نمایش داده می‌شود.

## منبع و محدودیت داده

نشانی پیش‌فرض `https://eitaa.com/howzeh_khalilshahr` است. نام و محتوای این صفحه مربوط به کانال حوزهٔ علمیهٔ باقرالعلوم است و الزاماً کانال مستقل هیئت نیست. نشانی را در `NewsRepository.CHANNEL_URL` تنها در صورت تأیید منبع صحیح تغییر دهید. دریافت‌کننده HTML عمومی با Jsoup را parse می‌کند؛ markup سرویس ممکن است تغییر کند یا پست‌ها برای استخراج عمومی در دسترس نباشند. در این شرایط خطا گزارش می‌شود و کش قبلی حفظ می‌گردد.

فقط پست‌هایی که از HTML واقعی و دارای متن و شناسهٔ پایدار قابل‌شناسایی‌اند نمایش داده می‌شوند؛ حداکثر ۱۰ پست در SharedPreferences (JSON) نگهداری می‌شود. درخواست ناموفق کش را پاک نمی‌کند. اجرای اول baseline می‌سازد و اعلان جدید نمی‌فرستد؛ در بررسی‌های بعد فقط شناسه‌های تازه اعلان می‌شوند. اعلان در Android 13+ منوط به اجازهٔ کاربر است.

تب‌های شهدا و برنامه‌ها بر اساس هشتگ واقعی هر پست فیلتر می‌شوند (`شهدا`/`شهید`/`شهدای` و `برنامه`/`مراسم`/`برنامه‌ها`). زمان‌بندی WorkManager هر ۳۰ دقیقه با الزام اتصال شبکه است (بهینه‌سازی سیستم ممکن است اجرای دقیق را به تأخیر اندازد). برنامه علاوه بر کار دوره‌ای، هنگام شروع نیز یک بررسی فوری زمان‌بندی می‌کند.

## فناوری و نسخه‌ها

- JDK 17، Kotlin 1.9.23، Android Gradle Plugin 8.2.0، Gradle 8.4
- Compose BOM 2024.02.00 و Compose Compiler 1.5.11
- compileSdk/targetSdk 34، minSdk 24
- Jsoup 1.17.2، WorkManager 2.9.0

## ساخت و آزمون

پیش‌نیاز: JDK 17، Android SDK Platform 34، و اتصال اینترنت برای دریافت Gradle/وابستگی‌ها. از ریشهٔ پروژه اجرا کنید:

```sh
./gradlew testDebugUnitTest
./gradlew assembleDebug
```

در Windows از `gradlew.bat` استفاده کنید. اسکریپت‌های همراه Gradle 8.4 را از توزیع رسمی دریافت و اجرا می‌کنند؛ این بسته شامل `gradle-wrapper.jar` نیست، زیرا در محیط تهیه در دسترس نبود و فایل ساختگی جایگزین نشده است. برای تبدیل به Gradle Wrapper استاندارد، با Gradle 8.4 نصب‌شده `gradle wrapper --gradle-version 8.4` را اجرا و خروجی wrapper رسمی را commit کنید.

## ساختار

- `MainActivity.kt`: رابط Compose، فیلترها، درخواست تازه‌سازی و زمان‌بندی WorkManager
- `NewsRepository.kt`: دریافت HTTP، parse و کش SharedPreferences
- `FeedWorker.kt`: بررسی دوره‌ای و اعلان پست‌های جدید
- `Post.kt`: مدل، parser و منطق تشخیص شناسه‌های تازه
- `app/src/test`: آزمون‌های unit برای parsing، حذف تکراری و شناسهٔ جدید

## حریم خصوصی و مجوزها

مجوزها محدود به INTERNET، ACCESS_NETWORK_STATE و POST_NOTIFICATIONS هستند. اطلاعات ورود یا API key لازم نیست. محتوا فقط برای کش محلی ذخیره می‌شود و به سرویس دیگری ارسال نمی‌گردد. فایل `local.properties` در Git نادیده گرفته شده است.
