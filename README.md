# هیئت شهدای گمنام خلیل شهر | Android

یک پروژهٔ تک‌ماژولی Kotlin/Jetpack Compose با رابط فارسی RTL، تم تیرهٔ زغالی/سبز و جزئیات طلایی است. این برنامه خبر جعلی یا نمونه‌ای ندارد.

## نکتهٔ مهم دربارهٔ منبع
نشانی تنظیم‌شده `https://eitaa.com/howzeh_khalilshahr` صفحهٔ کانال حوزهٔ علمیهٔ باقرالعلوم را معرفی می‌کند، نه یک کانال مستقل هیئت. بر مبنای اطلاعات هنگام سفارش، صفحه فقط یک پست ویدیویی عمومی نشان می‌داد. برنامه تعداد را جعل نمی‌کند: حداکثر ۱۰ پست واقعاً قابل‌استخراج نمایش داده می‌شود و در صورت کمتر بودن، همان تعداد (حتی صفر) دیده می‌شود. دسترسی زنده به HTML منبع هنگام تهیهٔ این سورس انجام نشده و سازگاری parser با markup فعلی تضمین نمی‌شود.

## رفتار و محدودیت parsing
- دریافت با Jsoup از HTML عمومی؛ containerها: `.tgme_widget_message`, `.widget_message`, `.message`, `.eitaa-message`. متن از `.tgme_widget_message_text`, `.widget_message_text`, `.eitaa-message-text` و captionهای متداول خوانده می‌شود. الگوی صفحهٔ ایتا ممکن است متفاوت/تغییرپذیر باشد.
- `.eitaa-message` به‌عنوان container پست پذیرفته می‌شود؛ parser به متن غیرخالی و شناسهٔ پایدار `data-post`/`data-id` یا لینک نیاز دارد. محتوای metadata کانال به‌تنهایی خبر محسوب نمی‌شود. شناسهٔ واقعی صفحه ممکن است با این قواعد قابل‌شناسایی نباشد.
- تکرار سنجاق‌شده بر اساس شناسه حذف می‌شود؛ لینک منبع و timestampهای استاندارد datetime/date خوانده می‌شوند. اگر همهٔ پست‌ها زمان معتبر داشته باشند بر اساس زمان نزولی مرتب می‌شوند، وگرنه ترتیب منبع حفظ می‌شود. هشتگ‌ها از متن پست استخراج می‌شوند.
- کش حداکثر ۱۰ مورد در SharedPreferences ذخیره می‌کند. fetch ناموفق یا markup ناشناخته کش را تغییر نمی‌دهد؛ WorkManager آن را retry می‌کند. نخستین fetch موفق فقط baseline می‌سازد و اعلان نمی‌فرستد؛ fetchهای بعدی تنها شناسه‌های تازه نسبت به snapshot قبلی را اعلان می‌کنند. اعلان‌ها به مجوز runtime اندروید ۱۳+ نیاز دارند.
- تب شهدا هشتگ‌های `شهدا`/`شهید`/`شهدای` را فیلتر می‌کند و برنامه‌ها `برنامه`/`مراسم`/`برنامه‌ها` را. هیچ پست یا متن نمایشی ساختگی در این فیلترها قرار ندارد.
- بارگذاری فوری در شروع و کنترل تازه‌سازی، به‌علاوه کار یکتای دوره‌ای متصل‌به‌شبکه با بازهٔ ۳۰ دقیقه (نه زمان‌بندی دقیقه‌ای دقیق).
- ظاهر بر اساس تصویر مرجع بازطراحی شده است؛ تصویر مرجع در محتوای اپ embed نشده است. فایل فونت Mitra ارائه نشده و در پروژه وجود ندارد. مالک دارای مجوز می‌تواند `app/src/main/assets/mitra.ttf` را اضافه کند؛ در غیر این صورت فونت سیستم استفاده می‌شود.

## ساخت
نیاز: JDK 17، Android SDK با API 36، Gradle 8.13. نسخه‌ها: AGP 8.11.1، Kotlin و Compose compiler plugin 2.2.20، Compose BOM 2025.08.00، minSdk 23، targetSdk 35، Jsoup 1.18.3، WorkManager 2.11.2.

در این تحویل Gradle/JDK/Android SDK محلی و فایل معتبر `gradle-wrapper.jar` در محیط سازنده موجود نبود؛ بنابراین wrapper ساختگی درج نشده است. در Android Studio پروژه را باز و Sync کنید، یا در محیطی که Gradle 8.13 و SDK API 36 دارد از ریشه اجرا کنید:

```sh
gradle testDebugUnitTest
gradle assembleDebug
```

Android Studio می‌تواند wrapper معتبر بسازد: `gradle wrapper --gradle-version 8.13`; سپس فایل‌های واقعی تولیدشده را اضافه و commit کنید.

## CI و مجوزها
GitHub Actions از JDK 17 و Gradle 8.13 استفاده می‌کند، آزمون unit و `assembleDebug` را اجرا می‌کند. مجوزهای برنامه فقط INTERNET، ACCESS_NETWORK_STATE و POST_NOTIFICATIONS هستند. هیچ token یا credential لازم نیست.

## فایل فونت اختیاری
اگر مالک فونت با حقوق لازم فایل `mitra.ttf` را در `app/src/main/assets/` قرار دهد برنامه آن را به‌صورت اختیاری بارگذاری می‌کند؛ در غیر این صورت fallback سیستمی است.
